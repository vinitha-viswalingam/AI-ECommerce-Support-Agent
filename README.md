# AI-Powered E-Commerce Customer Support Agent

A Streamlit-based e-commerce customer support demo using tool-style functions and session memory.

## Features

- Order tracking
- Return and refund eligibility
- Product search
- Product recommendations
- FAQ handling
- In-session conversation memory

## Technologies

- Python
- Streamlit
- JSON
- GitHub

## Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
